# StripDesk

StripDesk 用于把一次水平底片扫描整理成有片号的档案出片。原始像素留在项目中，成片可单张复查、排到样片板或整包下载。

```sh
./start.sh
```

打开 <http://127.0.0.1:19906/>。使用 `STRIP_PORT` 可切换本机端口。服务使用 Compose 的 `strip-data` 命名卷，`./start.sh stop` 停止工作台。

## 出片流程

1. 上传扫描原图，或载入标明合成性质的山景练习条。
2. 设置起点、统一帧距、张数、首张片号和上下边。原图显示有编号的实尺寸导线。
3. 查看选定行带的纵向暗带曲线。连续暗列显示为有坐标的区间。可分别调整每列暗值上限及暗像素占比。
4. 在原图点检两侧或片基，查看原色、当前正片色，用附近 5×5 中值设置 RGB 片基。
5. 选择负片转正、保留原色或成片裁切比例。按片号预览正片及其原图画幅位置、明暗截限读数。
6. 打开样片板，对照同条底片上的各个片号。保存出片后可下载快照 ZIP，含来源 PNG、逐帧正片、样片板、CSV 与设置。
7. 若一张成片需要更进一步的影像处理，可在选定片号后送往照片准备。

## 像素与输入约定

- 单页 PNG、JPEG、TIFF、BMP 或 WebP。每边 8 至 4096 像素，最多 800 万像素，文件不得超过 24 MiB。导入时遵循 EXIF 方向并转换为 RGB8 PNG。请把物理片条横向扫描。
- 每条取 1 至 24 张，坐标从原图左上角起算；右边和下边为半开界。固定比例出片从所选帧的中心作最大整数画幅裁切，像素维持原尺寸。
- 负片转正按片基逐通道估算，不提供胶卷型号专用色彩校正。暗带是选定高度上低于阈值的灰阶像素占比，用来对照手工导线。
- 保存的出片包含来源摘要、出片设置、编号和每张画幅。变更当前设置后，可下载原版的出片。
- 合成练习条使用确定性的山景、深色帧间带、片基和齿孔，适合从头演练。
